# FlingerIA
Asistente Android local para conversación, Luau y Roblox Studio. Versión 0.1: base compilable, UI Compose, persistencia de almacenamiento Android-scoped, contexto y seam `LocalLLMEngine`.

## Roadmap
1. Integrar llama.cpp Android como módulo NDK y Qwen2.5-Coder-1.5B-Instruct Q4_K_M.
2. Descarga reanudable con SHA-256 y streaming de tokens.
3. Historial, scripts, ajustes, modos CLIENTE/SERVIDOR/MODULE y pruebas en Galaxy Tab A8.

El workflow en `.github/workflows/app.yml` compila, prueba y publica la APK debug.
